# アサガオ領収書 🌼

**登録不要・完全無料・データはどこにも送信されない**領収書ジェネレーターです。

👉 **今すぐ使う:** https://taku0826.github.io/asagao-receipt/

## 特徴

- ✍️ **リアルタイムプレビュー** — 入力した内容がその場で領収書に反映されます
- 🖨️ **印刷 / PDF保存** — ブラウザの印刷機能でそのままきれいなPDFに
- 🧾 **インボイス対応** — 登録番号(T+13桁)を記載すれば適格簡易請求書として使えます
- 💴 **内訳の自動計算** — 税込金額から税抜金額・消費税額(10%/8%軽減税率)を自動で逆算
- 📮 **収入印紙欄の自動判定** — 現金で5万円以上のときだけ印紙貼付欄を自動表示(振込・電子交付は不要)
- 🔴 **朱印スタンプ** — 発行者の姓から朱印風のハンコを自動生成
- 🔒 **完全ローカル動作** — サーバーに一切データを送信しません。入力内容はあなたのブラウザの中だけ

## 使い方

1. ページを開く
2. 宛名・金額・但し書き・発行者を入力する
3. 「印刷 / PDF保存」ボタンを押す

それだけです。アカウント登録も、メールアドレスの入力も要りません。

## 仕組み

単一のHTMLファイルだけで動作します。ビルドなし、依存ライブラリなし。
`index.html` をダウンロードしてオフラインで使うこともできます。
